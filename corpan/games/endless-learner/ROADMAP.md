# Endless Learner - Iteration Plan

## Phase 1: Core loop stability
- Solidify phrase fetching + voice playback (no overlap, repeat cadence).
- One-answer-at-a-time flow with clear correct/wrong/miss feedback.
- Basic input + accessibility (keyboard, click, mobile tap zones).
- Tune default timing constants for relaxed play.

## Phase 2: Visual clarity + juice
- Add lane depth, motion trails, and more dramatic answer approach.
- Expand feedback cues (sound, glow, slight camera shake).
- Improve HUD typography + legibility for long phrases.

## Phase 3: Difficulty scaling
- Gradual speed increases based on streak.
- Multiple answers at once, mixed correct + incorrect.
- Introduce “chain” prompts (two prompts in parallel).

## Phase 4: Content diversity
- Better distractor selection (same domain/level but different meaning).
- Add alternative correct answers (synonyms/variants).
- Optional romanization toggles + advanced script-only modes.

## Phase 5: Theme packs
- Scene variants (Paris hoverboard, metro runner, space train).
- Character skins + board/runner variations.
- Music and ambience by domain or language.

## Phase 6: Meta systems
- Daily runs and seasonal goals (offline-friendly).
- Progression milestones with unlockable experiences.
- Achievements tied to accuracy and cadence.
