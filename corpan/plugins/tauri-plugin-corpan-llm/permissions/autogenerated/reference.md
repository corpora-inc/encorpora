## Default Permission

Default permissions for the Corpán on-device LLM plugin

#### This default permission set includes the following:

- `allow-llm-status`
- `allow-llm-load`
- `allow-llm-chat`
- `allow-llm-stop`
- `allow-llm-unload`
- `allow-llm-query-pack-db`
