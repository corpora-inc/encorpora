## Default Permission

Default permissions for the haptics plugin

#### This default permission set includes the following:

- `allow-impact`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`haptics:allow-impact`

</td>
<td>

</td>
</tr>

<tr>
<td>

`haptics:deny-impact`

</td>
<td>

</td>
</tr>
