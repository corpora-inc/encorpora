## Default Permission

Default permissions for the STT plugin

#### This default permission set includes the following:

- `allow-prepare`
- `allow-start-session`
- `allow-stop-session`
- `allow-cancel-session`
- `allow-is-available`
- `allow-get-status`
- `allow-wipe-model`
- `allow-install-model`
- `allow-validate-model`
- `allow-register-listener`
- `allow-remove-listener`
