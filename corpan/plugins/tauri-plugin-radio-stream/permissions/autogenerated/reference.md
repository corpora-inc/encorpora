## Default Permission

Default permissions for the radio-stream plugin

#### This default permission set includes the following:

- `allow-play`
- `allow-pause`
- `allow-resume`
- `allow-stop`
- `allow-set-volume`
- `allow-register-listener`
- `allow-remove-listener`
