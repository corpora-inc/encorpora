## Default Permission

Default permissions for the asr-native (OS-native dictation) plugin

#### This default permission set includes the following:

- `allow-capabilities`
- `allow-is-available`
- `allow-ensure`
- `allow-start-session`
- `allow-stop-session`
- `allow-cancel-session`
