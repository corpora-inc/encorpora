
## bundle.resources is intentionally empty

The SQLite database is delivered via `include_bytes!("../../../dja/release.sqlite3")` in
`db.rs`, which embeds it directly in the binary at compile time. It is then written to
`app_data_dir()` on first launch. Tauri's `bundle.resources` is **not** used for
database delivery — do not re-add a resource entry for any `.sqlite3` file.

## gen/ modifications

Files under `gen/` are generated by Tauri but have manual edits that must be
preserved across regeneration.

### gen/apple/Info.plist

Add:
```xml
	<key>LSApplicationQueriesSchemes</key>
	<array>
		<string>App-Prefs</string>
		<string>prefs</string>
	</array>
```

### gen/android/app/proguard-rules.pro

Replaced default boilerplate with active rules:
- `-keepclassmembers` for `@JavascriptInterface` methods
- `-keepattributes SourceFile,LineNumberTable` for readable crash stacks
- `-keep` rules for `@TauriPlugin`, `@InvokeArg`, and `@Command` annotated classes

### gen/android/app/src/main/java/com/corpora/corpan/MainActivity.kt

Added beyond the default `onCreate`:
- `onDestroy()` override with defensive WebView teardown (recursive `stopLoading` +
  `loadUrl("about:blank")` + detach + `destroy()`) to avoid `destroyFunctor` SIGSEGV
- `OnBackPressedCallback` in `onCreate` that calls `finish()` to prevent back-press ANR

### gen/apple/corpan_iOS/Info.plist (UIBackgroundModes)

Add:
```xml
<key>UIBackgroundModes</key>
<array>
    <string>audio</string>
</array>
```
Required for Stargate Reader background audio playback. Also added to
`ios/project.yml` template so it survives Xcode project regeneration.

### gen/android/app/src/main/AndroidManifest.xml (background audio)

Add permissions:
```xml
<uses-permission android:name="android.permission.FOREGROUND_SERVICE" />
<uses-permission android:name="android.permission.FOREGROUND_SERVICE_MEDIA_PLAYBACK" />
<uses-permission android:name="android.permission.WAKE_LOCK" />
```

Add service inside `<application>`:
```xml
<service
    android:name="com.corpora.audio_keepalive.AudioKeepAliveService"
    android:foregroundServiceType="mediaPlayback"
    android:exported="false" />
```

Required for Stargate Reader background audio playback via foreground service.

### gen/android/app/build.gradle.kts

Added to `release` build type:
- `ndk { debugSymbolLevel = "FULL" }` — uploads native debug symbols in the AAB
  for symbolicated crash stacks in Play Console
