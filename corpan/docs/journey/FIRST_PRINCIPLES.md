# Journey — First Principles (the rethink)

> Written after driving the real thing on-device and hating it. The current feed
> is a **silent text-translation drill** (read "uno", tap "one"). That is the
> worst mode of the worst language apps. This doc throws it out and rebuilds the
> core loop from what actually makes humans acquire language.

## What acquisition actually requires (not opinion — SLA research)

1. **Comprehensible input is the engine.** You acquire language by *understanding
   messages* a little above your level. Everything else serves this.
2. **Hearing is primary.** Listening is the main channel. Text is a crutch that
   should shrink over time, never the centerpiece.
3. **Meaning conveyed directly** — image, scene, glyph, audio, context — not
   translated to L1. Direct method. Bonus: audio + image are *language-neutral*,
   so the same card works across all 54² pairs. L1 text is the fallback, not the
   default.
4. **Retrieval at expanding intervals.** You're asked to recall right at the edge
   of forgetting. Invisible SRS, never a "review session" you dread.
5. **Output with feedback.** Speaking/producing, gently corrected.
6. **Flow, not tests.** The affective filter is real. It must feel like play you
   can't lose. No red X, no "you failed," no anxiety.

## What the current build gets wrong (why it feels empty)

- **Text-translation drills, not comprehension.** Read a word, pick a word. No
  hearing, no meaning-in-the-world, no message. Empty.
- **Assessment is a separate screen**, then a fixed drill. The learner feels
  *processed*, not *met*. The adaptivity is invisible in the moment.
- **Passive teach cards** (see + hear + tap Continue) have no stakes, no
  retrieval → they feel like dead air.
- **Nothing accelerates** when you're crushing it. A fast learner is bored.

## The core loop: the "comprehension beat"

Every card is ONE loop. No exceptions, no passive cards.

```
HEAR    target-language audio plays (always — this is the point)
GRASP   meaning is present as image / scene / glyph  (L1 text only as fallback)
ACT     one gesture proves you understood, or you produce the language
LAND    instant feedback that itself teaches; next beat already there
```

First-exposure and retrieval are the **same gesture**. Scaffolding makes early
beats inferable (an image, a cognate, fewer options, slower audio); the
scaffolding falls away as mastery grows. You are *always hearing the language*
and *always doing something that means something*.

## Continuous invisible assessment (the "calibrator")

Kill the separate placement screen. **The feed is the assessment.** Every answer's
correctness *and latency* is a probe.

- Start gentle. The engine watches.
- Nailing them fast and clean → it **accelerates, visibly**: frequency-rank jumps,
  skips whole clusters, the frame warms, the jumps get bigger. ("You're flying.")
- Stumbling → it quietly slows, reteaches, and reschedules the item to return in a
  few beats. No penalty, no red.

Within ~60 seconds the learner *feels a system that gets them*. The engine already
has the primitives (placement probes, jump-offers, fast-forward, FSRS spacing) —
we stop hiding them behind a screen and make them **felt in the feed**.

## The first 60 seconds, es→en, rebuilt

- You hear a warm voice: **"one."** Three big tiles: the glyphs **1 · 2 · 3**. Tap
  **1**. ✓ warm chime, it settles. *(meaning via glyph — zero translation, universal)*
- **"two."** Tap **2**. ✓ faster now.
- **"hello"** over a waving-hand image → tap the greeting among three scenes. ✓
- 5-for-5 under ~2s each → the frame warms, a soft ▸▸, and it **jumps** past the
  rest of the number drills: **"Good morning"** — you hear it, match the morning
  scene.
- Miss one? No red X. It replays slower, shows one more clue, and quietly comes
  back in ~4 beats.

You never chose a level. You never tapped Continue. You never read a silent word.
You *heard English and understood it*, faster and faster. That is the feel we are
building toward.

## Build order (highest feel-per-risk first)

1. **Audio-first everywhere.** Every opening beat plays the target audio and is
   answerable by ear. No silent text-translation cards in the opener. *(recipe +
   card wiring; TTS already works)*
2. **Meaning via glyph/image** for the concrete openers (numbers, greetings,
   objects) using the image pack + number glyphs. L1 text becomes fallback.
3. **Felt calibration.** Surface the fast-forward: a clean fast streak visibly
   accelerates the path (bigger jumps), the frame warms. Rip the separate
   placement screen out of the default path.
4. **No passive cards.** Replace see+hear+Continue with an active first-exposure
   beat (hear → infer from scaffold → act).
5. **Juice** (PREMIUM_SCROLL §3): the tactile layer so every landing feels good.

Ground every change on-device (es→en), not in tests alone.
