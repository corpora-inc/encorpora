## Cross-team contracts (do not drift)

1. **Word glosses.** New string keys `wg.<word>` in `courses/en/strings/<lang>.json`, compiled into the existing
   `strings` table (schema stays 1 — OTA-safe). `course.yaml` gains `l1_full_support: [es]`. Validator: every word
   item (pinned + auto-expanded) MUST have `wg.` in `en` + every `l1_full_support` lang; sparse elsewhere.
   `resolveWord` reads `wg.<ref_id>` at `nativeLang` with **no English fallback**; absent → `native` undefined.
2. **Translation-integrity guard.** `runtime.prepareExercise` never emits a translation-form card
   (choice_pick toNative/toTarget, flip_recall, text-axis match_pairs) for an item whose `native` face is absent —
   it swaps the activity type (pattern of the existing sttFallback). Renderers additionally refuse to render
   identical-language translation semantics (defense in depth).
3. **Direction.** Translation cards always carry explicit `params.direction ∈ {toNative, toTarget}`; `targetOnly`
   is reserved for non-translation forms.
4. **STT three-state policy.** whisper unsupported → swap to listen_type (as today). Supported + model missing →
   keep speak_echo; SpeakEcho/cap-pronounce offers Tiny-model install inline; decline emits
   `detail.flags.sttDeclined = true`; runtime then swaps the rest of the session. Installed → full scoring round.
5. **Verdict-less recall.** FlipRecall reveal→continue emits an outcome with no self-verdict; engine grades it
   Good-clamped with `flags.aggregateBinned` semantics (R9). No "did you get it?" buttons anywhere.
6. **Advance.** Any explicit button press advances immediately. Settled answer cards auto-advance (short delay +
   existing countdown ring); swipe remains as manual override; failed cards never auto-advance.
7. **New UI strings** go in `en/common.json` under `journey.*`; each team lists its new keys in its report;
   a dedicated i18n wave fills all locales afterward (check:i18n is a hard build gate). cap-pronounce strings live
   in its own `strings.ts` table.
