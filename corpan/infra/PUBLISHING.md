# Narration Pack Publishing — Operations Guide

Last updated: 2026-03-11

## Overview

Narration packs are trilingual audiobook narrations (996 segments per language)
packaged as ZIPs and served to the Corpan mobile app via CloudFront CDN backed
by S3.

**Key concept**: A *narration* = one voice reading one book in one language.
Multiple narrations per language are possible (different voices). Each narration
is a separate downloadable pack (~50-60 MB each).

## Architecture

```
┌──────────────┐     ttsctl publish     ┌──────────────────────┐
│  DGX Spark   │ ─────────────────────▶ │  S3: corpan-prod     │
│  (build box) │   boto3 + publisher    │  └─ artifacts/       │
└──────────────┘   profile              │     ├─ catalog.json  │
                                        │     └─ narrations/   │
                                        │        └─ *.zip      │
                                        └──────────┬───────────┘
                                                   │ OAC
                                        ┌──────────▼───────────┐
                                        │  CloudFront CDN      │
                                        │  PriceClass_100      │
                                        │  (US/EU/Asia)        │
                                        └──────────┬───────────┘
                                                   │ HTTPS
                                        ┌──────────▼───────────┐
                                        │  Corpan App          │
                                        │  (iOS / Android)     │
                                        │  fetchCatalogV2()    │
                                        │  download_and_install│
                                        └──────────────────────┘
```

## S3 Layout

```
s3://corpan-prod/
├── artifacts/
│   ├── catalog.json                              # CatalogV2 — app fetches this
│   └── narrations/
│       ├── monte-alban-ian-en-0.1.0.zip          # Book 01 narrations (5 langs)
│       ├── monte-alban-ian-es-0.1.0.zip
│       ├── monte-alban-ian-zh-0.1.0.zip
│       ├── monte-alban-ian-ar-0.1.0.zip
│       ├── monte-alban-ian-fr-0.1.0.zip
│       ├── the-unconquered-people-ian-en-0.1.0.zip  # Book 02 narrations (5 langs)
│       └── ...
├── sources/
│   └── voices/data/                               # Voice reference WAVs backup
│       └── *.wav
└── staging/                                       # Temp uploads (future use)
```

CloudFront origin_path is `/artifacts`, so CDN URLs map:
- `https://<cdn-domain>/catalog.json` → `s3://corpan-prod/artifacts/catalog.json`
- `https://<cdn-domain>/narrations/foo.zip` → `s3://corpan-prod/artifacts/narrations/foo.zip`

## ZIP Contents

Each narration ZIP contains audio and book data only — **not** the reader code:

```
{packId}/
├── manifest.json              # Narration metadata (generated by ttsctl publish)
├── segments.json              # English text segments
├── segments_es.json           # Spanish translated segments
├── segments_zh.json           # Chinese translated segments
├── audio_manifest_{lang}.json # Word-level timestamps for this voice/language
└── audio/
    └── {lang}/
        └── *.m4a              # 996 mastered M4A audio files
```

> **Reader code is deployed separately.** The Stargate Reader JS/CSS bundle
> (`dist/app.js`, `dist/app.css`) is deployed to GitHub Pages via the
> `hover-runner-pages.yml` workflow, triggered automatically on push to `main`
> when files under `corpan/packs/**` change. Narration ZIPs do NOT need to be
> re-published when the reader code changes — only when audio or book data changes.

## AWS Credentials

Two sets of credentials exist:

### 1. Admin credentials (`~/.env`)
```
AWS_ACCESS_KEY=AKIA...    # NOTE: key name is AWS_ACCESS_KEY not AWS_ACCESS_KEY_ID
AWS_SECRET_ACCESS_KEY=...
```
- Used for: Terraform apply, IAM management
- Terraform needs `AWS_ACCESS_KEY_ID` env var, so export with:
  ```bash
  export AWS_ACCESS_KEY_ID=$(grep '^AWS_ACCESS_KEY=' ~/.env | cut -d= -f2 | tr -d '"')
  export AWS_SECRET_ACCESS_KEY=$(grep '^AWS_SECRET_ACCESS_KEY=' ~/.env | cut -d= -f2 | tr -d '"')
  ```

### 2. Publisher credentials (`~/.aws/credentials`)

Created by Terraform. Populate from env or secrets manager — never hardcode:
```bash
# One-time setup (get values from Terraform output or team vault)
aws configure --profile corpan-publisher
# prompts for: aws_access_key_id, aws_secret_access_key, region (us-east-2)
```

Resulting `~/.aws/credentials` entry:
```ini
[corpan-publisher]
aws_access_key_id = <from terraform output or secrets manager>
aws_secret_access_key = <from terraform output or secrets manager>
```
- IAM user: `corpan-dgx-publisher`
- Scoped permissions: S3 PutObject/GetObject/DeleteObject on `staging/*`, `artifacts/*`, and `sources/*`, plus CloudFront invalidation
- Used by: `ttsctl publish --profile corpan-publisher`

Region config in `~/.aws/config`:
```ini
[profile corpan-publisher]
region = us-east-2
```

## Publishing Commands

### Publish a narration
```bash
PACK=~/encorpora/books/fascinating-curiosities/01-mystery-of-monte-alban/pack
ttsctl publish "$PACK" --lang en --voice-id ian-narration --voice-name Ian
ttsctl publish "$PACK" --lang es --voice-id ian-narration --voice-name Ian
ttsctl publish "$PACK" --lang zh --voice-id ian-narration --voice-name Ian
```

Full options:
```
ttsctl publish <pack_dir>
  --lang TEXT              Language code (en, es, zh) [required]
  --voice-id TEXT          Voice identifier [required]
  --voice-name TEXT        Display name [required]
  --version TEXT           Narration version (default: 0.1.0)
  --bucket TEXT            S3 bucket (default: corpan-prod)
  --profile TEXT           AWS profile (default: corpan-publisher)
  --reader-dist PATH       [LEGACY] Stargate reader dist/ — reader code now deploys via GH Pages, not narration ZIPs
  --tier [public|premium]  (default: public)
  --cdn-domain TEXT        CloudFront domain (default: d38iwc9748jekz.cloudfront.net)
```

The command does 3 things:
1. **Package**: Creates ZIP in /tmp with manifest, segments, audio, dist
2. **Upload**: Pushes ZIP to `s3://corpan-prod/artifacts/narrations/`
3. **Catalog**: Downloads catalog.json, upserts narration entry, re-uploads

### Verify uploads (using Python since aws CLI is not installed)
```python
import boto3, json
s3 = boto3.Session(profile_name='corpan-publisher').client('s3')

# List ZIPs
resp = s3.list_objects_v2(Bucket='corpan-prod', Prefix='artifacts/narrations/')
for obj in resp['Contents']:
    print(f"{obj['Key']}  ({obj['Size'] / 1024 / 1024:.1f} MB)")

# Read catalog
resp = s3.get_object(Bucket='corpan-prod', Key='artifacts/catalog.json')
print(json.dumps(json.loads(resp['Body'].read()), indent=2))
```

### Invalidate CDN cache (after republish)
```python
import boto3, time
cf = boto3.Session(profile_name='corpan-publisher').client('cloudfront')
cf.create_invalidation(
    DistributionId='E1RDNUCVE70SCI',
    InvalidationBatch={
        'Paths': {'Quantity': 1, 'Items': ['/*']},
        'CallerReference': str(int(time.time()))
    }
)
```
Note: Cache invalidation takes ~10-30 seconds. The `ttsctl publish` command does NOT
auto-invalidate — run this after all publishes are done.

```json

  "version": 2,
  "generatedAt": "2026-03-09T21:29:45.116972+00:00",
  "narrations": [
    {
      "id": "monte-alban-ian-en",
      "bookId": "book_monte_alban",
      "bookTitle": "The Mystery of Monte Albán",
      "language": "en",
      "voiceId": "ian-narration",
      "voiceName": "Ian",
      "version": "0.1.0",
      "downloadUrl": "https://d38iwc9748jekz.cloudfront.net/narrations/monte-alban-ian-en-0.1.0.zip",
      "sha256": "f8c24e61...",
      "sizeMb": 58.3,
      "series": "Fascinating Curiosities of Human History",
      "volume": 1,
      "tier": "public",
      "purchase": { "type": "free", "priceLabel": "Free" }

```

## Pack ID Convention

Pack IDs are derived from book ID + voice + language:
```
book_monte_alban + ian-narration + en → monte-alban-ian-en
```
Logic: strip `book_` prefix, replace `_` with `-`, strip `-narration` from voice, append `-{lang}`.

ZIP filename: `{packId}-{version}.zip` → `monte-alban-ian-en-0.1.0.zip`

## Fresh Clone Setup

Audio files and voice WAVs are **not stored in git**. They are served from CloudFront
(narrations) and S3 (voice references). After a fresh clone, run the hydration scripts
to populate local directories:

### Audio files (for Vite dev server)
```bash
# Downloads narration ZIPs from CloudFront and extracts audio/*.m4a to local pack dirs
./corpan/infra/hydrate-audio.sh

# Filter by book or language
./corpan/infra/hydrate-audio.sh --book book_monte_alban --lang en
```

### Voice reference WAVs (for TTS generation)
```bash
# Requires AWS CLI + corpan-publisher profile
./corpan/infra/hydrate-voices.sh
```

### Voice backup (upload new voices to S3)
```bash
./corpan/infra/sync-voices-to-s3.sh
```

These scripts live in `~/encorpora/corpan/infra/`. Audio dirs are gitignored via
`**/pack/audio/` and voice WAVs via `voices/data/*.wav`.

## Adding a New Book's Narrations

1. Complete TTS pipeline: `ttsctl generate <pack> --lang en/es/zh`
2. Validate: `ttsctl validate <pack> --lang en/es/zh`
3. Master: `ttsctl master <pack> --lang en/es/zh --all`
4. Publish all 3 languages:
   ```bash
   ttsctl publish <pack> --lang en --voice-id <id> --voice-name <name>
   ttsctl publish <pack> --lang es --voice-id <id> --voice-name <name>
   ttsctl publish <pack> --lang zh --voice-id <id> --voice-name <name>
   ```
5. Invalidate CDN cache if updating existing packs
6. Verify catalog.json has correct entries
