## Default Permission

Default permissions for the iOS Share plugin

#### This default permission set includes the following:

- `allow-share-file`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`ios-share:allow-share-file`

</td>
<td>

Enables the share_file command without any pre-configured scope.

</td>
</tr>

<tr>
<td>

`ios-share:deny-share-file`

</td>
<td>

Denies the share_file command without any pre-configured scope.

</td>
</tr>
</table>
