# School and workbook shell review

Class, school and learner workbook screens use the shared AppShell logo, drawer and content region. Phone content has no outer card or rail; desktop content uses `--width-content-wide`.

Start class occupies the action slot on Today and opens the existing `…/start` board. Its space stays reserved across Class tabs. Past classes retain Grades and Time. School tabs follow the existing API capabilities; the solo-school Overview redirect is preserved. Family navigation excludes school-only administration. Authorization and server code are unchanged.

Learner workbooks at `/learners/:learnerId/workbooks*` use the plain shared shell. Their URL identifies a learner independently of the learner selected in Progress, so displaying Progress tabs could imply the wrong learner context.

No URLs merge and no redirects are added. Existing redirects remain intact. Public school marketing, sign-in, joining by code, school setup, first-run steps and trial screens retain their frames. Signed-in school invitation acceptance and the school chooser use the plain shared shell.

The drawer extends the existing place switcher with accessible classes and learners, includes schools reached through inherited district access, adds one Class and one School group link, and retains the account identity and Sign out footer.

## Shared changes

- The place list loads ahead from authorized org/class queries. If a menu click precedes completion, AppShell keeps the logo box fixed with the standard busy indicator; a second click cancels. The drawer opens with its complete destination list, avoiding inserted rows under the pointer.
- AppShell renders Class/School tabs and the Today action from the existing route data. Frame observers reuse loader results without a second mount fetch; explicit invalidation still refreshes changed data.
- AppBar lets its tab column shrink, so seven tabs scroll within one row on phones.
- Tabs scrolls the active tab into view from either direction, including Back/Forward.
- Pathways keeps its public catalog observer above the keyed learner view. This prevents an in-flight catalog request from being canceled and repeated when the selected learner resolves, as detected by the shell stability check.
- Print rules hide the shared bar and remove its reserved height, preserving printable cards and reports.
- School table headings stick below the fixed bar; grids with an internal scrollport keep their local heading position.
- Workbook marking/stack footers span the viewport with centered contents after removing the rail offset.
- Time header dates near the end of the strip align inward to fit the column at 768 px.
