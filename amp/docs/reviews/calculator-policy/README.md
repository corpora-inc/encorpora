# Calculator policy review

The practice workspace offers a calculator for “Prices and counts for a group.” These synthetic screenshots use a generated cafe purchase problem with no account or learner data. The calculation shown is (4.60 + 1.50) × 14 = 85.40 dollars.

`npm run test:calculator-ui` exercises the shared policy with this applied problem and verifies that multiplication facts have no calculator control. It also checks keyboard and touch interactions, result insertion, focus return, safe areas and viewport fit.
