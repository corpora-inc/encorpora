# Dynawalla program docs

Read in this order on your first task. Skim headings after that.

**Start here**

- [MISSION.md](MISSION.md) — what it is, the core promise, the engagement ethics, the
  locked founder decisions.
- [STATUS.md](STATUS.md) — current milestone, merged PRs, in-flight work, blockers.
  **Update this in the PR that changes it, not afterwards.**
- [ACCEPTANCE_CRITERIA.md](ACCEPTANCE_CRITERIA.md) — the definition of done. This is
  what the program is graded against.
- [MASTER_PLAN.md](MASTER_PLAN.md) — milestones in dependency order, decomposed into
  PR-sized units with exit criteria.

**Reference**

- [ARCHITECTURE.md](ARCHITECTURE.md) — directory layout, the eight layers, the
  boundaries that are enforced by tests.
- [CURRICULUM.md](CURRICULUM.md) — the skill graph, generator families, mal-rules,
  what V1 covers and what it does not.
- [ADAPTIVE_LEARNING.md](ADAPTIVE_LEARNING.md) — the three-layer learner model, the
  scheduler, the invariants, the simulation harness.
- [EXPERIENCE_DESIGN.md](EXPERIENCE_DESIGN.md) — the core loop in milliseconds,
  reactions, the character, construction, art direction and the hostile reference board.
- [PACK_SYSTEM.md](PACK_SYSTEM.md) — why V1 has no downloadable packs and what would
  have to be true to add them.
- [RELEASE_ENGINEERING.md](RELEASE_ENGINEERING.md) — CI topology, the merge queue,
  release triggers, build numbers, the traps.
- [TEST_STRATEGY.md](TEST_STRATEGY.md) — what is tested where, and what tests cannot
  tell us.
- [GATES.md](GATES.md) — the CG-series curriculum gates and EG-series engine gates, each
  with an owning PR.
- [STORE.md](STORE.md) — store bootstrap, compliance posture, what is automatable and
  what needs a browser.

**Governance**

- [RISKS.md](RISKS.md) — every risk with a mitigation and an owner.
- [DECISIONS.md](DECISIONS.md) — the ADR index, including the open founder decisions.
- [DECISIONS/](DECISIONS/) — one ADR per irreversible choice.
- [PLAYTEST-PROTOCOL.md](PLAYTEST-PROTOCOL.md) — who the evaluator is, the session
  protocol, what gets recorded, and what this instrument cannot tell us.

Agent rules for this directory tree: [`../AGENTS.md`](../AGENTS.md), which is a delta
over the root [`../../AGENTS.md`](../../AGENTS.md).
