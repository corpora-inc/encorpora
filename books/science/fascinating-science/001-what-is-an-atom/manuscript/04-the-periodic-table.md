# The Periodic Table

The periodic table is a chart that organizes every known element. The table arranges elements by their number of protons, from smallest to largest. Hydrogen is first with one proton. Helium is second with two protons. The table continues all the way to oganesson with one hundred and eighteen protons.

The periodic table has rows and columns. The rows are called periods. The columns are called groups. Elements in the same group share similar properties. This is why the table is called periodic. The properties repeat in a regular pattern.

The elements on the left side of the table are metals. Most elements are metals. Metals are shiny. Metals conduct electricity. Metals conduct heat. Iron, copper, gold, and aluminum are all metals.

The elements on the right side of the table are nonmetals. Nonmetals include oxygen, nitrogen, carbon, and sulfur. Nonmetals do not conduct electricity well. Nonmetals are the elements that make up air, water, and living things.

A few elements sit on the boundary between metals and nonmetals. These elements are called metalloids. Silicon is a metalloid. Silicon conducts electricity a little bit, but not as well as a metal. This property makes silicon useful in computer chips.

The noble gases are in the last column on the right. Helium, neon, argon, krypton, xenon, and radon are noble gases. Noble gases almost never react with other elements. Their electron arrangements are already stable. They do not need to form bonds.

A Russian scientist named Dmitri Mendeleev created the first periodic table in 1869. Mendeleev arranged the elements by their properties and noticed the repeating pattern. He left gaps in his table where he predicted unknown elements should be. Scientists later discovered those elements. Every prediction was correct.

The periodic table is one of the most powerful tools in science. If you know where an element sits on the table, you can predict how it will behave.
