# Voice Clone Reference Files

These WAV files are reference audio for Chatterbox TTS voice cloning.
Backed up to `s3://corpan-prod/sources/voices/data/`. Rehydrate locally
via `corpan/infra/hydrate-voices.sh`.

## `samples/` — per-narrator language evaluation samples

`voices/data/samples/{narrator}/<lang>.{wav,m4a}` holds short same-content
clips generated by the `sample_*.py` scripts in `../scripts/`. They exist
so we can A/B a narrator across languages without re-running TTS.

**Not tracked in git** (see `voices/data/samples/` in root `.gitignore`).
Source of truth: `s3://corpan-prod/sources/voices/data/samples/`. Pull
with `hydrate-voices.sh`; push new samples with
`aws s3 sync voices/data/samples/ s3://corpan-prod/sources/voices/data/samples/ --profile corpan-publisher`.
